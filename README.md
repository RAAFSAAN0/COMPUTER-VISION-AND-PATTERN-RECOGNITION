# Computer Vision and Pattern Recognition

A research-oriented repository containing implementations, experiments, and projects in computer vision, deep learning, neural networks, generative models, and pattern recognition.

This repository showcases my programming experience in Python, model development, experimental evaluation, and research-oriented machine learning workflows. It includes projects ranging from traditional machine learning algorithms to deep learning architectures, image classification, face detection, generative adversarial networks (GANs), and latent-space anomaly detection.

- Explainable AI (XAI) and Model Interpretability

- Medical Image Segmentation

## Repository Structure

### 1. Behavioral and Explanation-Based Monitoring of Image Classifier Degradation Under Progressive Corruption

**Focus:** Model reliability, image classification, and explainability under progressively corrupted input data.

This research project investigates classifier behavior under image corruption and explores explanation-based approaches to understanding changes in model performance.

**Contents:**
- `2.ipynb` — Jupyter notebook containing the project's implementation and experiments.
- `Manuscirpt.pdf` — Research manuscript documenting the study.

### 2. Comparative Analysis of U-Net Variants for Brain Image Segmentation

**Focus:** Deep learning for medical image segmentation.

This project explores U-Net-based architectures for image segmentation, with an emphasis on comparing model variants and examining their performance on brain imaging tasks.

**Contents:**
- `attention-unet.ipynb` — Implementation and experiments involving Attention U-Net.
- `final_assignment_paper.pdf` — Project report and associated analysis.
- `transfer-learning.ipynb` — Notebook exploring transfer learning techniques.

### 3. Face Detection and Recognition Using CNN and Haar Cascades

**Focus:** Computer vision, face detection, and recognition.

This project explores a face detection and recognition pipeline combining Haar cascade-based detection with convolutional neural networks (CNNs).

**Contents:**
- `IPYNB FILE/` — Notebook-based implementation.
- `TRAINING MODEL.ipynb` — Model training workflow.
- `WEBCAM CONNECTION.ipynb` — Webcam integration and real-time input handling.
- `MODEL ARCHITECTURE (TRAINED).h5` — Saved trained model in HDF5 format.
- `MODEL ARCHITECTURE (TRAINED).keras` — Saved model in Keras format.
- `README.md` — Project-specific documentation.

### 4. Latent-Space Anomaly Detection

**Focus:** Generative modeling, latent representations, and anomaly detection.

This project explores generative models and latent-space representations as part of an investigation into anomaly detection and the analysis of learned image distributions.

**Contents:**
- `All Pipeline Codes/` — Implementation notebooks for the model pipelines.
- `stylegan-2-cifar.ipynb` — StyleGAN2-related experiments using CIFAR data.
- `stylegan-2-mnist.ipynb` — StyleGAN2-related experiments using MNIST data.
- `wgan celebA.ipynb` — Wasserstein GAN experiments using CelebA data.
- `wgan-cifar.ipynb` — WGAN experiments using CIFAR data.
- `wgan-mnist.ipynb` — WGAN experiments using MNIST data.
- `README.md` — Additional project documentation.

The notebooks provide a starting point for examining generative model implementations and their use in latent-space research. Refer to the individual notebooks and project documentation for the specific methods and experimental configurations.

### 5. Neural Networks and Traditional Machine Learning

**Focus:** Neural networks, classification algorithms, and pattern recognition.

This section contains implementations and experiments involving foundational machine learning methods.

**Contents:**
- `NN.ipynb` — Neural network implementation and experiments.
- `knn.ipynb` — K-nearest neighbors (KNN) implementation and experiments.
- `README.md` — Additional documentation.

## How to Explore the Repository

1. Browse the project directories to identify an area of interest.
2. Open the relevant `.ipynb` file on GitHub to inspect the source code, methodology, and available outputs.
3. Read the accompanying PDF manuscripts or reports for research context and analysis.
4. Review project-specific README files for additional setup instructions.
5. For local execution, install the dependencies required by the selected notebook and configure the appropriate dataset paths.

Dataset access, pretrained weights, and hardware requirements may vary by project.
